# KOROBOS

Second Brain Operating System unifying knowledge management, habit tracking, and analytics.

## Structure

- `frontend/`: Next.js web application
- `backend/`: FastAPI Python microservices
- `infrastructure/`: deployment configurations (Docker, K8s, Terraform)
- `docs/`: architecture and design documents
- `scripts/`: development and database lifecycle scripts

## Quickstart

Please read [docs/development/setup.md](docs/development/setup.md) to bootstrap the development environment locally using Docker Compose and Make.
